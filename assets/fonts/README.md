# Fonts

Drop `.ttf` files here and reference them by filename stem in a campaign's
`style.captions.font`, e.g. a file named `Montserrat-ExtraBold.ttf` is
selected with `font: Montserrat-ExtraBold`.

With nothing here, the pipeline uses DejaVu Sans Bold, which ships in the
container.

This folder is gitignored — check the licence before redistributing any font.
